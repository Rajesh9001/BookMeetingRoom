# BookMeetingRoom


## Overview
BookMeetingRoom is a platform where users can register, login, and search for available meeting rooms based on location, building, date, and time. Users can view all available rooms along with their floor and timings that are not booked. They can book a room for a specific time and date. Admins have the ability to approve or reject bookings and add more rooms to the system.

### Features
- **Register and Login**: Users can create an account and login to access the platform.
- **Search Meeting Rooms**: Search for available meeting rooms by location, building, date, and time.
- **View Available Rooms**: View all available rooms along with their floor and timings that are not booked.
- **Book Meeting Rooms**: Book a room for a specific time and date.
- **Admin Approval**: Admins can approve or reject bookings.
- **Add More Rooms**: Admins can add more rooms to the system.
